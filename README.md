**What was optimized:**

Неоптимізований запит: Чотири рази поспіль повністю перераховує, з'єднує та групує один і той самий набір даних у вкладених підзапитах, щоб знайти мінімум і максимум. Це змушує базу робити повний перебір таблиць (Parallel Seq Scan).

**Оптимізований запит:**

Фільтрує та з'єднує таблиці (playlists, music, users) лише один раз у CTE filtered_songs.

Групує та рахує треки лише один раз у CTE cnt_songs.

Використовує віконні функції ROW_NUMBER(), щоб знайти найменшу та найбільшу кількість за один прохід.

Використовує індекси (added_date, song_id, user_id, subscription_type), що замінило повний перебір диска на швидкісний Bitmap Index Scan.
